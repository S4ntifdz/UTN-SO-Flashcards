# Flashcards de Sistemas Operativos

Sitio estático de estudio con 149 tarjetas de conceptos y 47 prácticas con estilo de parcial. Incluye filtros, búsqueda y progreso guardado en el navegador.

## Despliegue en Vercel

Importá este repositorio como proyecto con el framework **Other**. No requiere comando de build ni variables de entorno: Vercel sirve `index.html` desde la raíz.

También se puede abrir `index.html` directamente en un navegador. Tailwind se carga desde CDN; los estilos principales están incluidos en el archivo.
